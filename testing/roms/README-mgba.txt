Place GBA (or GB/GBC) test ROMs in this directory after installing the package.

The destination directory on the SD card is:

  Roms/Game Boy Advance (MGBA)/

An SD-card pak takes precedence over the system one, so the ordinary GBA.pak and
gpSP are left alone and still work as before. A GB/GBC ROM placed here runs under
mGBA rather than Gambatte, which is the comparison worth having.
